# Attribution

The video retrieval experiments use [DiDeMo](https://github.com/LisaAnne/LocalizingMoments).
Its upstream `video_licenses.txt` records original source URLs and individual
Creative Commons terms. Media retain their original licenses, including BY,
BY-SA, BY-NC and BY-NC-SA 2.0; this repository does not grant new rights to them.

CLIP uses the upstream OpenAI model and Transformers implementation. Refer to
their respective model and software licenses before reuse.

Raw media, annotation captions, embeddings and model weights are not distributed
here. The notebooks show recorded experiment results, selected query IDs,
timestamp geometry and attribution metadata. Saved analysis outputs do not
change the terms applying to the original material.
